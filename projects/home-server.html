PROJECT DETAIL

Home Server & CCTV Monitoring

A self-hosted Linux server environment built for website services, remote access, and CCTV monitoring using containerized applications.

Project Overview

This project explores Linux server administration and self-hosted services using Debian 12 and Docker.

The environment includes web applications, reverse proxy management, secure remote access, and CCTV monitoring through Frigate.

Technologies

Debian 12 Docker Cloudflare Tunnel Nginx Proxy Manager Frigate Nextcloud WordPress Tailscale

Main Components

  • Linux server administration
  • Docker container management
  • Reverse proxy using Nginx Proxy Manager
  • Remote access through Cloudflare Tunnel
  • Self-hosted Nextcloud and WordPress
  • CCTV monitoring using Frigate

Project Goals

To gain practical experience in server administration, containerization, networking, remote access, and self-hosted infrastructure.
