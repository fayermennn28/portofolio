PROJECT DETAIL

Smart Parking Management System

A web-based parking management system designed to monitor parking slot availability and provide parking statistics for a campus parking area.

Project Overview

This project is developed as an academic project in Informatics Engineering. It focuses on building a web-based parking management platform with real-time monitoring as the intended IoT feature.

The web application is being developed first. Physical sensor and microcontroller integration will be implemented after the hardware circuit is completed.

Technologies

HTML5 CSS3 JavaScript Bootstrap 5 PHP Native MySQL REST API ESP32 RFID

Main Features

  • Parking slot management
  • Parking availability monitoring interface
  • Parking statistics and dashboard
  • RFID-based identification concept
  • Planned ESP32 and sensor integration

Project Goals

To develop a centralized parking management application that can help campus administrators monitor parking information and manage parking activities more efficiently.
